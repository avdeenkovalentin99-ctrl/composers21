# Композиторы XXI века

Сайт на React, TypeScript и Vite. Действующая главная — `src/app/pages/FestivalPageLegacy.tsx`; слово `Legacy` здесь не означает неиспользуемый файл. Текущая разработка интро находится в `src/app/components/intro/` и на маршруте `/intro-test`.

## Запуск и проверка

```sh
npm ci
npm run dev
npm test
npm run build
npm run preview -- --host 127.0.0.1 --port 4173
```

При работающем preview: `npm run test:browser`. Для другого адреса: `npm run test:browser -- http://127.0.0.1:PORT`. Браузерные проверки используют установленный Chromium Playwright; на новой машине установите его командой `npx playwright install chromium`.

Для проверки запуска с ограниченным хранилищем, заполненной квотой и заблокированным видео: `node scripts/browser-startup-smoke.mjs http://127.0.0.1:4173 chromium` и та же команда с `webkit` вместо `chromium`. WebKit устанавливается через `npx playwright install webkit`. Это эмуляция телефона и проверка браузерного движка; физический iPhone/Safari проверяется отдельно. Результаты сохраняются в `.tmp-device/`.

`npm test` проверяет кодировку, импорт и генерацию биографий, дубли карточек и существующую анимационную логику. Браузерный сценарий проверяет метаданные, Tab/Escape, окно Академий, Back, шрифты и изображения на мобильном и большом экране. Результаты сохраняются в `.tmp-improvements/`.

## Контент

| Исходник | Назначение |
| --- | --- |
| `tmp_data/bios_raw.md` | Солисты |
| `tmp_data/composers_bios.md` | Композиторы |
| `tmp_data/ensembles_raw.md` | Ансамбли и оркестры |
| `src/app/data/concertProgrammes.ts` | Концертные программы |

После редактирования биографий выполните `npm run build:bios`. `personDetails.ts` и `participants.generated.ts` генерируются; вручную их не редактируют. Дубли slug внутри одной категории останавливают генерацию. Одна персона в разных категориях допустима. Для разных версий биографии источник задаётся явно в `scripts/build-bios.ts`, без выбора по длине.

`*.legacy.ts` данных участвуют в текущей сборке. `tmp_data/niko_refs/` содержит исходные фотографии страницы фестиваля. Эти файлы не являются временным мусором.

## Шрифты и изображения

Приложение использует WOFF2 и WebP с несколькими размерами. Оригиналы сохранены в `assets/originals/`, `src/assets/participants/` и `tmp_data/niko_refs/`. Список источников — `scripts/asset-sources.json`.

```sh
python -m pip install --target .tmp-tools -r scripts/requirements-assets.txt
npm run assets:build
```

Шрифты конвертируются с сохранением полного набора символов и метрик. Фотографии сохраняются в WebP с качеством 88 без увеличения исходного разрешения; логотипы — без потерь после уменьшения размеров. Учитываются EXIF-ориентация, прозрачность и цветовые профили. Скрипт обновляет `public/assets/optimized/`, `public/fonts/*.woff2` и `src/app/data/optimizedImages.generated.ts`. Эти результаты нужны сборке и должны храниться в Git; Python на сервере публикации не требуется.

Для изображений страниц используются `ResponsiveImage` и `MotionImage`: они подставляют подготовленные `srcset`, размеры и сохраняют заданные стили кадрирования. Новый портрет добавляется в `src/assets/participants/`, после чего запускается обработка ресурсов. Для остальных изображений добавьте источник в `scripts/asset-sources.json`. Лицензии шрифтов сохраняются вместе с ресурсами.

Фотографии шести ансамблей имеют явно закреплённый локальный приоритет в `performers.ts`; импорт не должен снова перекрывать их внешним CDN. Для ансамблей предусмотрена нейтральная заглушка при ошибке изображения.

Эмблема на главной видна независимо от готовности видео. Запасные кадры находятся в `src/assets/hero/`; после замены видео пересоздайте их через `node scripts/capture-hero-posters.mjs` при работающем preview актуальной сборки. Кадры извлекаются из самих роликов, видеофайлы при этом не изменяются.

Ролики эмблемы — декоративная часть сцены без элементов управления. Копии `logo-film-wide.mp4` и `logo-film-portrait.mp4` подготовлены из корневых оригиналов командой FFmpeg `-map 0:v:0 -c:v copy -an -movflags +faststart`: видеодорожка сохранена без перекодирования, звук удалён, данные для начала воспроизведения перенесены в начало файла. Запуск выполняется через `play()`: HTML-атрибут `autoPlay` намеренно отсутствует, поскольку Safari может принудительно показывать на нём системную кнопку в режиме энергосбережения. Системные ограничения воспроизведения всё равно требуют проверки на реальном iPhone.

## Архив и локальные файлы

`archive/2026-10-29/` содержит прежние компоненты, референсы, резервные копии и старые публичные ресурсы. `manifest.json` фиксирует исходные пути, причины переноса и SHA-256. Архив исключён из сборки приложения и проверки кодировки; восстановление требует проверки актуальных импортов и источников ресурсов.

`.env.local`, диагностические логи, `.tmp*/`, кэши TypeScript и Python остаются локальными и исключены из Git. Шаблон конфигурации — `.env.example`. Оригиналы дизайна и отчёты не следует помещать в `public`: его содержимое копируется в публикацию целиком.

## Публикация

Push в `main` запускает `.github/workflows/deploy.yml`: установка зависимостей, сборка и передача `dist` на сервер. Перед пушем выполните тесты, сборку и браузерную проверку. Документы аудита и дальнейшие задачи находятся в `docs/audits/2026-10-28/`.
